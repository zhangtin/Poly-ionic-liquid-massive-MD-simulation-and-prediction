# base_gromacs — SPC/E liquid-water base project

Development and test base project for mdflow V0.1: 1728 rigid SPC/E water molecules (OPLS-AA atom types) in a 3.72412 nm cubic periodic box, 5184 atoms.

> This is a **test system** for validating the Script Builder, not a validated research system.

## Regenerating / verifying

```bash
python3 tools/make_conf.py upstream/spc216.gro conf.gro --n 2   # regenerate conf.gro
bash tools/fetch_upstream.sh /tmp/upstream_check                # re-fetch and verify upstream files from the official repository
sha256sum -c SHA256SUMS                                         # check that this project is unmodified
```

After changing any file in this project, regenerate `SHA256SUMS`, otherwise mdflow reports `BASE_PROJECT_MODIFIED`. The base-project hash changes too, and with it every job ID and random seed (this is by design).
